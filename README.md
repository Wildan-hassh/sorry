# Halaman Permintaan Maaf

Buka `index.html` di browser untuk melihat halaman.

## Mengganti foto

Simpan enam foto di folder yang sama dengan nama berikut:

- `foto-1.jpg`
- `foto-2.jpg`
- `foto-3.jpg`
- `foto-4.jpg`
- `foto-5.jpg`
- `foto-6.jpg`

Jika memakai nama atau format lain, ubah bagian `src="foto-...jpg"` di `index.html`.

Musik sudah tersedia sebagai `musik-permintaan-maaf.mpeg` dan akan diputar melalui tombol musik di halaman. Pada sebagian browser Android, musik baru bisa mulai setelah tombol disentuh karena aturan autoplay.

## Notifikasi tombol “Iya”

Agar kamu mendapat notifikasi saat tombol “Iya” ditekan tanpa membuat penerima login:

1. Buat form gratis di Formspree dan salin endpoint seperti `https://formspree.io/f/xxxxxxxx`.
2. Endpoint Formspree sudah dipasang di `index.html`.
3. Pastikan email penerima sudah dikonfirmasi di akun Formspree.

## Mengunggah ke GitHub Pages

Unggah isi folder ini ke repository GitHub, lalu pilih `Settings` → `Pages` → `Deploy from a branch` → branch `main` dan folder `/ (root)`.
